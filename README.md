# Sales Data Analysis using Excel

## Project overview
A beginner-friendly Data Analyst portfolio project using a sample sales dataset. The Excel workbook includes raw sales records, KPI formulas, revenue summaries, and charts.

## Tools
- Microsoft Excel
- CSV data

## Files
- `sales_analysis.xlsx` — workbook with `Sales_Data` and `Summary` sheets.
- `sales_data.csv` — raw sample dataset (80 fictional orders).
- `README.md` — project explanation and analysis questions.

## Questions to explore
1. What is the total revenue and estimated profit?
2. Which region generated the most revenue?
3. Which product generated the most revenue?
4. How many units were sold?
5. What is the average revenue per order?

## How to use
1. Download `sales_analysis.xlsx` and open it in Microsoft Excel.
2. Go to the `Summary` sheet to view KPI formulas and charts.
3. Go to `Sales_Data` to filter and sort the sample orders.
4. Try building a PivotTable by region, product, and sales channel.

## Dataset note
The 80 order records are synthetic sample data created for practice; they do not represent a real company.
